Herramienta de automatización

Fabby Social Automation

Fabby Social Automation es una herramienta operada por ÑukawaStudio para organizar la preparación y publicación de contenido en las cuentas sociales que el titular autoriza.

Leer política de privacidadLeer términos de uso

Cómo funciona

  1. El titular conecta Google Drive y elige fotografías para preparar contenido.
  2. La herramienta envía una propuesta de imagen y texto a Telegram para revisión.
  3. El usuario decide si aprueba, rechaza o solicita cambios.
  4. Tras una aprobación explícita, el flujo publica en las cuentas vinculadas de Instagram o Facebook y registra el resultado para evitar duplicados.

Uso de datos de Google

La integración solicita acceso autorizado a Google Drive para leer los archivos seleccionados y la información técnica necesaria para preparar el borrador. Los datos obtenidos de Google no se venden ni se usan para publicidad. Solo se comparten con los servicios conectados necesarios para cumplir la acción que el usuario pidió, como Telegram para la revisión y Meta para la publicación aprobada.
